# Delícias da Bilu

Site oficial da Delícias da Bilu, com cardápio de geladinhos gourmet, contato pelo WhatsApp e informações sobre o serviço de personal chef.

## Publicação no GitHub Pages

O site é totalmente estático e não exige etapa de compilação. No GitHub, abra **Settings → Pages**, selecione **Deploy from a branch**, escolha a branch **main** e a pasta **/(root)**.
